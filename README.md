# Hydrz Tap

## How do I install these formulae?

`brew install hydrz/tap/<formula>`

Or `brew tap hydrz/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "hydrz/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
